# Contributor Code of Conduct

MarketSpec is intended to be a technically rigorous and welcoming open-source project.

## Expected behavior

Contributors and maintainers should:

- discuss ideas and disagreements respectfully;
- critique code, specifications, evidence, and reasoning rather than people;
- make space for questions and good-faith corrections;
- disclose relevant conflicts of interest when they materially affect a technical discussion;
- avoid harassment, threats, discriminatory language, unwanted sexual attention, doxxing, or publication of private information;
- respect responsible-security-reporting boundaries.

## Scope

This code of conduct applies to project repositories, issue and pull-request discussions, review threads, and other public or private project spaces controlled by MarketSpec maintainers.

## Enforcement

Project maintainers may edit or remove content, close or lock discussions, reject contributions, or restrict participation when behavior violates this policy.

For conduct concerns that can be reported safely in public, open an issue with only the minimum information needed to request maintainer attention. Do not put private personal information or security-vulnerability details in a public issue.

Serious security concerns should use the private process in [SECURITY.md](SECURITY.md).

Maintainers should apply this policy based on documented behavior in the project space, without retaliation against good-faith bug, security, or correctness reports.
